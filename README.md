# Automated-Probe-Station

GUI-приложение (Python + PySide6) автоматизированной зондовой станции:
снятие вольт-амперных характеристик (ВАХ) с образцов тонких фотопроводящих
слоёв источником-измерителем Keithley 2636B с автоматической коммутацией
пары контактов зондовой станцией.

## Текущая стадия

Работоспособная демо-версия в каталоге `demo/`:

- полный цикл измерения: задание параметров -> развёртка V1..V2 с шагом Vs
  и задержкой Δt -> график ВАХ в реальном времени -> сохранение результата
  (.vac — JSON с параметрами и точками) в папку образца
  `<рабочая_папка>/<образец>/`;
- два конфига: `config.json` в рабочей папке (скелет параметров) и
  `local_config.json` в папке каждого образца; правки файлов из консоли
  автоматически подтягиваются в GUI (обратной записи из GUI нет);
- история измерений: дерево папок рабочей директории с поиском, ленивым
  раскрытием и контекстными меню; галочка рисует кривую измерения поверх
  живого графика своим цветом, по окончании измерения свежая кривая сразу
  показывается из сохранённого файла;
- без подключённого прибора драйвер K2636B автоматически переходит в режим
  симуляции — приложение (и тест) полностью работоспособны без железа;
- зондовая станция — программная заглушка `demo/PS.py` с интерфейсом
  будущего реального драйвера;
- автомат состояний измерения: idle / measurements / waiting.

## Установка и запуск

Требуется Python 3 (разработка ведётся на 3.14) и make.

```
make install        # создать .asp_env и поставить зависимости из requirements.txt
make run            # запустить GUI
make run d=опыты_1  # рабочая папка demo/data/опыты_1/ (короткое имя)
make run d=/путь    # произвольная рабочая папка (абсолютный путь)
make test           # headless-проверка всего сценария без железа и дисплея
make clean-data     # очистить demo/data/ от результатов прогонов
make help           # список команд
```

Зависимости (версии зафиксированы): PySide6, PyVISA, pyserial, pyqtgraph, numpy.

## Архитектура кратко

- Два потока: GUI-поток (виджеты, график) и worker QThread (контроллер и
  драйверы приборов). Обмен — только сигналами Qt через QueuedConnection,
  блокирующие вызовы прибора не тормозят интерфейс.
- Контроллер — автомат из трёх состояний; цикл развёртки крутится в очереди
  событий worker-потока на QTimer, без sleep.
- Подробности: ТЗ — `docs/terms_of_reference.md`, схема сигналов —
  `docs/signals_scheme.md`.

## Настройка

Рабочая папка выбирается флагом `make run d=<имя|путь>` или кнопкой
«Рабочая папка…» в блоке истории (выбор запоминается между запусками);
по умолчанию — `demo/data/` (константа `DEFAULT_WORKDIR` в
`demo/session.py`).

В рабочей папке лежит `config.json` — скелет параметров измерения. При
первом старте измерения с новым образцом создаётся папка
`<рабочая_папка>/<образец>/` с `local_config.json` (копия config.json) —
дальше параметры этого образца регламентируются им. Секция `values` —
рабочие значения полей GUI, секция `limits` — жёсткие границы напряжения,
шага, задержки и тока. Оба файла правятся только из консоли; изменения
подтягиваются в GUI автоматически (во время измерения — после stop).
Те же диапазоны контроллер валидирует повторно на старте измерения.
Диапазоны контактов чипов — в `CHIP_RANGES` (`demo/PS_widget.py`).

Оформление — светлая и тёмная темы (тёмная — для работы в затемнённом
помещении во время опытов), переключатель в правой колонке окна;
палитры — `demo/theme.py`.
